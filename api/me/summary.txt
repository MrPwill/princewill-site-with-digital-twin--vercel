#### 🔄 Pipeline Architecture
```mermaid
flowchart LR
  A[Lead Researcher] --> B[CRM + Dedup]
  B --> C[ICP Scoring]
  C --> D[Qualification]
  D --> E[Sales Manager]
  E --> F[Email Manager]
  F --> G[SendGrid]
  G --> H[Webhook]
  H --> I[Reply Classifier] --> J[Conversation Manager]
```

#### 🤖 Multi-Agent System
| Agent | Responsibility |
|-------|---------------|
| 🔍 Lead Researcher | Queries Serper API to discover prospects |
| 🛡️ Input Guard | Validates lead data, blocks invalid entries |
| 📊 ICP Scorer | Scores leads against `config/icp_rules.yaml` |
| ✉️ Sales Manager | Generates persona-based email drafts |
| 📤 Email Manager | Formats, guards, and sends via SendGrid |
| 🔄 Reply Classifier | Processes inbound webhook responses |

#### ⚙️ Configuration Example
```env
OPENAI_API_KEY=...
SENDGRID_API_KEY=...
SERPER_API_KEY=...
EMAIL_MODE=test  # or 'live'
DRY_RUN=false
SDR_DEBUG=true   # enables JSON logging
```
